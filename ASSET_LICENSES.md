## Not included or not CC0

The official Locomo character, app icon, wordmark, signing artwork, website
artwork, and combined product lockups are not included in this repository and
are governed by [TRADEMARKS.md](TRADEMARKS.md).

Starter songs are not stored in this Git history. If Immortal Company later
publishes an optional starter-song archive, that archive must include its own
exact file manifest, hashes, CC0 designation, and full CC0 text. The source app
does not require a starter-song pack.

The Geist and Inter font files are not CC0. Each remains under SIL Open Font
License 1.1, with its license beside the font under
`src/renderer/public/licenses/`.
