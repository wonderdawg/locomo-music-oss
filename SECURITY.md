# Security policy

Please do not open a public issue for a suspected vulnerability. Email
`support@locomomusic.com` with the subject **Locomo Music security report** and
include the affected OSS version or commit, reproduction steps, likely impact,
and any proof of concept that can be shared safely.

Immortal Company, Inc. will acknowledge the report and coordinate disclosure
after assessing it. This policy does not promise a bug bounty or a particular
resolution timeline.

Security fixes target the current default branch and latest public Locomo Music
OSS release. Official Locomo Music binaries have a separate release lifecycle,
even when a vulnerability affects both projects.
